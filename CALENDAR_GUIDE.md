# Our 2026 Journey - Couple Calendar

A modern, cinematic, and fully editable romantic calendar designed for long-distance couples.

## Features

### 🎨 Design
- **12 unique monthly themes** with distinct color palettes and emotional moods
- **Cinematic imagery** for each month telling your love story
- **Elegant typography** using Inter and Playfair Display fonts
- **Dark premium aesthetic** with gradient overlays and glass effects
- **Responsive design** works on all screen sizes

### 📅 Calendar Functionality
- Clean Monday-start grid layout
- Large readable day numbers
- Visual progress indicator showing current month
- Smooth transitions between months

### 💝 Special Dates
- **5 types of special occasions:**
  - ❤️ Anniversary (Heart icon)
  - ⭐ Birthday (Star icon)
  - 🔒 First Meeting (Lock icon)
  - 🔥 Special Memory (Flame icon)
  - 💕 Valentine's Day (Heart icon)
- Hover over marked dates to see notes
- Fully customizable - add, edit, or remove any special date

### ✏️ Edit Mode
1. Click "Edit Calendar" or press `E`
2. Click any day to add/edit special dates
3. Choose the type of occasion
4. Add a romantic note (optional)
5. Save and see it beautifully displayed

### ⌨️ Keyboard Shortcuts
- `←` Previous month
- `→` Next month
- `E` Toggle edit mode
- `H` or `?` Show keyboard shortcuts help

### 🖨️ Print/Export
- Click "Print/Save" to create a physical calendar
- Each month prints on its own page
- High-quality layout optimized for A4/Letter size
- Colors preserved for stunning printed results

## Customization Tips

1. **Update dates in Edit Mode** - Personalize all special occasions
2. **Change quotes** - Edit the monthsData in App.tsx to use your favorite quotes
3. **Replace images** - Update imageUrl fields with your own couple photos
4. **Adjust colors** - Modify color and accentColor values for each month
5. **Add more special date types** - Extend the code to include new icons

## Technical Details

- Built with React + TypeScript
- Styled with Tailwind CSS
- Icons from Lucide React
- Fonts: Inter (sans-serif) + Playfair Display (serif)
- Fully responsive and print-ready

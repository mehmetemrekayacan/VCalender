
# VCalender

**En güncel sürüm:** [VCalender 0.0.3 Release](https://github.com/mehmetemrekayacan/VCalender/releases/latest)

VCalender, Electron ve React ile geliştirilmiş modern ve şık bir takvim uygulamasıdır. Kullanmak için doğrudan yukarıdaki release dosyasını indirip çalıştırabilirsiniz. Kurulum veya geliştirme adımlarına gerek yoktur.

## Features
- Monthly calendar view with navigation
- Date editing dialog
- Seasonal animations
- Window size selector
- Responsive design
- Customizable themes
- Background music support

## Project Structure
- `src/` - Main source code (React components, hooks, styles)
- `electron/` - Electron main and preload scripts
- `public/` - Static assets
- `build/` - Build outputs
- `release/` - Release artifacts

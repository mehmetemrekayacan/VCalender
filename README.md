# VCalender

VCalender is a modern, responsive calendar application built with Electron and React. It provides a beautiful and interactive interface for managing dates, events, and seasonal animations. The project leverages Vite for fast development and Tailwind CSS for styling.

## Features
- Monthly calendar view with navigation
- Date editing dialog
- Seasonal animations
- Window size selector
- Responsive design
- Customizable themes
- Background music support

## Getting Started

### Prerequisites
- Node.js (v16 or higher recommended)
- npm or yarn

### Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/yourusername/vcalender.git
   cd vcalender
   ```
2. Install dependencies:
   ```sh
   npm install
   # or
   yarn install
   ```


### Development
To start the development server:
```sh
npm run dev
# or
yarn dev
```

### Build
To build the application for production:
```sh
npm run build
# or
yarn build
```

### Electron
To run the Electron app:
```sh
npm run electron
```

## Project Structure
- `src/` - Main source code (React components, hooks, styles)
- `electron/` - Electron main and preload scripts
- `public/` - Static assets
- `build/` - Build outputs
- `release/` - Release artifacts
